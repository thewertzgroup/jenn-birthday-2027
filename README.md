# Jenn's Birthday Trip · June 2027

Static trip plan (Ireland · London · Riviera · Paris), published with GitHub Pages.
Prices checked Nov 21, 2026 for 2 adults; nothing booked.

- `template.html` + `build.py` → `index.html` (run `python3 build.py`)
- `images/` Wikimedia Commons photos (credits in `credits.json` and the page footer)
- `map.js` Leaflet + OpenStreetMap route map (Leaflet vendored in `vendor/`)
